#  POSTGRESQL ACADEMIC DB // SYSTEM REPOSITORY

> *“No vasto vazio do silício, dados colidem, tabelas persistem e o caos relacional é mantido sob controle por linhas de comando.”*

---

##  VISÃO GERAL DO SISTEMA

Este repositório documenta a implementação, modelagem e administração de banco de dados relacional utilizando **PostgreSQL** em ambiente acadêmico (Ciência da Computação). O foco central reside na interação direta com o sistema gerenciador de banco de dados (SGBD) por meio de interfaces de linha de comando (**PowerShell**), dispensando abstrações gráficas pesadas e focando na engenharia crua por trás dos motores de dados.

---

##  STACK TECNOLÓGICA & FERRAMENTAS

* **Motor SGBD:** PostgreSQL (Gerenciamento de Instância e Instanciação Local)
* **Interface de Controle:** PowerShell (Automação, Inicialização `initdb` e Controle `pg_ctl`)
* **Linguagem de Consulta:** SQL Padrão (DDL / DML / Constraints / Relacionamentos)
* **Controle de Versão:** Git & GitHub
